# Evaluación 2 — Extracción de Conocimiento en Bases de Datos

Repositorio con la solución de la Evaluación 2 de la materia **Extracción de Conocimiento en Bases de
Datos** (UTEQ). Contiene seis Jupyter Notebooks que aplican algoritmos de aprendizaje supervisado y no
supervisado sobre distintos conjuntos de datos, cubriendo regresión, clasificación, agrupación y reducción
de dimensionalidad.

Para cada ejercicio se documenta: justificación del algoritmo elegido, diseño del modelo paso a paso,
evaluación y optimización mediante búsqueda de hiperparámetros, y gráficas personalizadas con su
interpretación.

## Contenido

| Notebook | Tipo de problema | Algoritmo | Conjunto de datos |
|---|---|---|---|
| `01_Regresion_Beisbol.ipynb` | Regresión | Regresión Lineal | `beisbol.csv` |
| `02_Clasificacion_BreastCancer.ipynb` | Clasificación | Árbol de Decisión | `breast-cancer.csv` |
| `03_Agrupacion_Samsung.ipynb` | Agrupación | K-Means | `samsung.csv` |
| `04_PCA_ComprarAlquilar.ipynb` | Reducción de dimensionalidad | PCA | `comprar_alquilar.csv` |
| `05_Clasificacion_BreastCancer_LogReg.ipynb` | Clasificación (algoritmo alterno) | Regresión Logística | `breast-cancer.csv` |
| `06_Regresion_Beisbol_Ridge.ipynb` | Regresión (algoritmo alterno) | Regresión Ridge | `beisbol.csv` |

## Tecnologías
